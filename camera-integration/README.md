# تكامل وحدة الكاميرا

تحتاج الخدمة إلى وحدة كاميرا Note8 بالإصدار0.6 لإشارة أول إطار في التسجيل. لا تكفي0.5 لزر التسجيل التلقائي. ملف `0.6.patch` يبين التغييرات فوق المصدر0.5 المسلّم سابقاً، وتوجد حزمة الوحدة كاملة ضمن المخرجات المحلية للمهمة.

الخدمة لا تثبت روتاً أو Xposed ولا توسع نطاق حقن الوحدة. النطاق القائم يبقى كاميرا سامسونج وسناب على جهاز المستخدم المختبر. لا يمكن استخدام تطبيق الآيفون لاستبدال كاميرا iOS؛ هو متحكم بالنوت.
